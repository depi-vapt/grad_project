## 🚀 About The Project

Hash Cracker is a Python-based security and cryptographic auditing tool designed to identify hash algorithms, analyze password security, and perform efficient password recovery operations.

The project goes beyond traditional hash cracking by introducing **Hash Awareness** and **Encoding & Decoding** capabilities to provide a more comprehensive cryptographic analysis experience.

## ✨ Key Features

- 🔍 **Hash Identification:** Automatically identify hash algorithms such as MD5, SHA-256, and NTLM.
- 🧂 **Salt Awareness:** Detect and handle salted hashes.
- 🧠 **Hash Awareness:** Analyze hash characteristics, security levels, and potential weaknesses.
- 📖 **Dictionary Attack:** Test password candidates using custom wordlists.
- ⚡ **Brute Force Attack:** Perform controlled password recovery operations.
- 🚀 **Multi-threading:** Improve cracking performance through parallel processing.
- 🔄 **Encoding & Decoding:** Support common encoding formats such as Base64, Hex, and URL Encoding.
- 📊 **Audit Logging:** Store results, attempts, and execution times.
- 💻 **CLI / Web Dashboard:** Provide an accessible interface for managing operations.
